## 🔍 HTTP

HTTP stands for **HyperText Transfer Protocol**.

It is used for communication between a web browser and a web server. HTTP does not encrypt the data.

Example:

`http://example.com`

## 🔐 HTTPS

HTTPS stands for **HyperText Transfer Protocol Secure**.

It provides a more secure connection by encrypting the data transferred between the browser and the server.

Example:

`https://example.com`

## 📊 HTTP and HTTPS

| HTTP | HTTPS |
|---|---| 
| Less secure | More secure |
| Data is not encrypted | Data is encrypted |
| Uses `http://` | Uses `https://` |
| Suitable for basic communication | Used for sensitive information |
| No secure connection | Secure connection |
